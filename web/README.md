# 汽发转轴加工温度在线监测看板

## 启动

```powershell
cd E:\Desktop\tuixiu_protect\qifa_hongwai\qifa_hongwai_main\web
python app.py --serial-port COM3
```

默认监听 `127.0.0.1:8080`。若需局域网访问，使用 `python app.py --host 0.0.0.0 --port 8081`。

然后打开：

```text
http://127.0.0.1:8080
```

如果不传 `--serial-port`，程序会尝试自动选择一个串口。主站固件串口波特率为 `115200`。

网页已支持 **双从站** 显示：按 `sensor_id` 区分（1 和 2），曲线、卡片和统计都会分别展示。

## 上位机配置

页面右上角提供以下配置能力：

- 点位 1、点位 2 的显示名称配置；
- 每个点位独立温度校准，公式为 `校准温度 = 原始温度 × 系数 + 补偿值`；
- 保存校准参数后，历史入库温度会基于保留的原始温度重新计算；
- 串口和波特率配置，选择结果会持久保存；
- 10 分钟至 7 天的曲线窗口切换，也可以在曲线上使用鼠标滚轮缩放；
- 按时间范围和点位导出 UTF-8 CSV 历史数据。

## 测试模式

没有硬件时可以启动模拟数据：

```powershell
python app.py --simulate
```

## 数据库

测点超过 80 秒未收到新数据时，网页显示“设备失联”，实时温度、环境温湿度和电量清空为占位符，保留最后数据时间与历史曲线。监测接口失败时显示“监测服务断开”；新数据到达后自动恢复。超时参数为 `static/app.js` 中的 `SENSOR_OFFLINE_AFTER_MS`。

温度数据保存在当前目录的 `temperature.db`，表名为 `readings`。

## 贴图式设备组态

主页面默认自动加载 Three.js 转轴网格模型，以 `static/assets/green-cnc-lathe-twin-v3.png` 作为半透明 AI 背景。右上角可切换“贴图场景 / 三维模型”。生成提示词保存在图片同目录的 `.prompt.md` 文件中。实时温度、测点标签、连线与曲线由前端独立绘制，两种场景均可使用。

- 桌面采用左侧设备主视图、右侧双测点面板，场景下方汇总测点温度；平板与手机采用上下或纵向排列。
- “设备全景”可临时隐藏数据卡片，再点击“返回监测”恢复。
- 桌面可拖动测点和卡片标题；测点聚焦后可用方向键微调，按 Shift 加快移动。
- 位置保存在当前浏览器，双击拖动区域可恢复单项，“恢复布局”恢复全部。
- AI 场景仅用于设备组态展示，实际测温位置应按现场安装位置调整。
